Tech News Microsoft Begins 30-Day Countdown to Windows 10’s End

September 15, 2025 ● Tebuho Zongwana

Microsoft has officially started the 30-day countdown to the end of support for Windows 10, with the operating system set to lose security and feature updates after October 14, 2025.

The change affects Windows 10 version 22H2 across Home, Pro, Enterprise, Education, and IoT editions. Long-term servicing versions, including Windows 10 2015 LTSB and Windows 10 IoT Enterprise 2015 LTSB, will also reach the end of servicing on the same day.

After the deadline, devices running these versions will no longer receive monthly security patches or bug fixes. Without updates, users will face increasing risks from new vulnerabilities and emerging cyber threats.

To help ease the transition, Microsoft is offering an Extended Security Updates (ESU) program. For the first time, this option is available not only to businesses but also to individual consumers, allowing personal PCs to continue receiving essential security updates beyond the official end date.

Despite this option, Microsoft is strongly encouraging users to move to Windows 11, stressing that upgrading to the newer platform is the most secure and sustainable path forward.

With less than a month left, millions of Windows 10 users now face a critical decision: upgrade, pay for extended support, or remain on an unsupported system.
